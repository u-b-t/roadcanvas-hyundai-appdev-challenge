Route requests with waypoints
경유지를 포함한 경로 요청 방법을 안내합니다. requestRouteWithWaypoints()는 최종 목적지와 하나 이상의 경유지를 포함한 경로를 요청합니다. 목적지는 RouteInfo, 경유지는 RequestWaypointInfo로 구성하고, 두 값을 RouteWithWaypointsRequest에 전달합니다.

),

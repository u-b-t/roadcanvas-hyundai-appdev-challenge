Importing FusedLocation SDK
FusedLocation SDK를 사용하려면 Maven 저장소를 등록하고 앱 모듈에 SDK 의존성을 추가합니다.
Maven 저장소 등록​
프로젝트의 settings.gradle.kts 또는 settings.gradle에 FusedLocation SDK가 배포된 Maven 저장소를 추가합니다.
Kotlin DSL
Groovy
settings.gradle.kts
dependencyResolutionManagement {
repositories {
maven("https://nexus-playground.pleos.ai/repository/maven-releases/")
}
}
settings.gradle
dependencyResolutionManagement {
repositories {
maven {
url "https://nexus-playground.pleos.ai/repository/maven-releases/"
}
}
}

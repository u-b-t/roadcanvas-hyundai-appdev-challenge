Declaring permission
위치 데이터 접근 권한​
FusedLocation API 호출에 필요한 권한은 FusedLocation API Reference의 해당 API 상세 페이지에서 확인할 수 있으며, pleos.car.permission.FUSED_LOCATION이 정의되어 있습니다.
권한보호 수준사용 API
pleos.car.permission.FUSED_LOCATIONdangerousgetLastKnownLocation, registerFusedLocationCallback, unregisterFusedLocationCallback
권한 선언​
FusedLocation SDK의 위치 정보 API를 호출하려면 다음 권한을 AndroidManifest.xml에 선언해야 합니다.
AndroidManifest.xml
<manifest ...>
<uses-permission android:name="pleos.car.permission.FUSED_LOCATION" />
<application ... />
</manifest>
권한이 허용되지 않은 상태에서 권한이 필요한 API를 호출하면 API가 정상적으로 동작하지 않을 수 있습니다. 권한 요청과 결과 처리는 앱의 권한 처리 흐름에 맞게 구현하세요.
위치 접근 차단 상태​
차량의 현재 개인정보 보호 설정으로 위치 접근이 차단된 경우 showLocationAccessBlockedPopup()을 호출하여 사용자에게 접근 차단 상태를 안내할 수 있습니다.
이 API는 위치 접근을 허용하는 API가 아닙니다. 위치 데이터가 전달되지 않는 경우에는 콜백의 null 및 onError(Exception)을 함께 처리하고, 앱의 화면과 기능을 적절히 제한해야 합니다.
정보
Android의 ACCESS_COARSE_LOCATION, ACCESS_FINE_LOCATION, ACCESS_BACKGROUND_LOCATION에 관한 동작과 포그라운드·백그라운드 위치 접근 정책은 이 SDK 문서에서 별도로 보장하지 않습니다. Google Fused Location SDK의 설명을 Pleos Connect의 동작 보장으로 해석하면 안 됩니다.

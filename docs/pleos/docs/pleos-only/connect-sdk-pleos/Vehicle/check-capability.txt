Capability
checkXxxCapabilities로 기능 지원 여부와 허용 범위를 확인합니다. onComplete는 기능 단위 지원 정보를 반환합니다. 반환 형태는 API마다 다르며, 공통 모델은 capability 패키지를 참조하세요. 도메인 객체 획득은 Obtaining a domain object를, 상세 API 명세는 API Reference를 참조하세요.
이 문서 트리는 CapabilityConfig를 함께 반환하는 capability API를 기준으로 설명합니다.
타입설명
CapabilityConfig기능 단위 접근 수준(AccessType: NONE, READ, WRITE, READ_WRITE)
AreaBounds영역별 허용 값 범위(minValue, maxValue)
Map<Area, AreaBounds>영역(예: DoorArea)별 AreaBounds 맵
아래 예제는 Vehicle 인스턴스(vehicle)를 이미 초기화했다고 가정합니다.

Java
val door = vehicle.getDoor()
door.checkDoorPositionCapabilities(
onComplete = { config, areaMap ->
when (config.accessType) {
AccessType.READ, AccessType.READ_WRITE -> {
val bounds = areaMap[DoorArea(DoorValue.ROW_1_LEFT)]
// Use bounds?.minValue / bounds?.maxValue, then call getCurrentDoorPosition
}
else -> {
// NONE or WRITE only — disable UI or use an alternate flow
}
}
},
onFailed = { e: Exception ->
if (e is VehicleException) {
// Capability lookup failed: e.errorCode
}
}
)

Introduction
Vehicle SDK 소개​
Vehicle SDK는 차량 정보 조회 및 제어를 위한 API를 제공합니다. 3rd party 앱은 Vehicle SDK를 통해 Pleos Connect의 Vehicle Service에 연결합니다. Vehicle Service는 Android Automotive OS 위에서 동작하며, 3rd party 앱은 Vehicle SDK API로 차량 정보 조회 및 제어를 요청하고 Vehicle Service가 이를 처리합니다.
SDK 버전
이 가이드는 Vehicle SDK v2.3.2과 Vehicle Service v2.3.21을 기준으로 작성되었습니다.
진입점과 도메인 구조​
Vehicle SDK API는 Brake, CarInfo, Display, Door, DrivingMode, EvBattery, Fuel, HVAC, Light 등 도메인별 인터페이스로 제공됩니다. Door, Brake 같은 도메인 객체는 직접 생성하지 않고, Vehicle SDK의 진입점인 Vehicle 인스턴스의 getDoor(), getBrake()와 같은 getXxx()로만 얻습니다. 획득한 도메인 객체에서는 capability·get·set·callback API를 호출합니다. Capability(checkXXXCapabilities)는 기능 지원 여부와 허용 값 범위를 확인하고, get은 현재 값을 조회하며, set은 값을 설정합니다. Callback은 리스너를 등록해 상태 변화를 구독합니다.
차량 서비스 연결은 initialize()로 시작하고, 사용이 끝나면 release()로 해제합니다. 차량 통신은 IPC이므로 capability·get·set 결과는 즉시 반환되지 않고 onComplete·onFailed 비동기 람다로 전달됩니다. 비동기 콜백이 끝나기 전에 release()를 호출하지 않도록 주의해 주시기 바랍니다.
도메인설명
Brake브레이크 페달, 주차 브레이크 상태 조회
CarInfo차량 기본 정보(외부 크기, 제조사, 연식 등) 조회
Display인포테인먼트 표시 데이터 단위(온도 단위 등) 조회/설정
Door도어 열림/닫힘, 잠금/해제 제어 및 상태 조회
DrivingMode드라이브 모드, 크루즈 컨트롤 정보 조회
EvBatteryEV 배터리·충전 상태 및 전비(효율) 조회
Fuel연비 등 연료 관련 정보 조회
HVAC난방·환기·공조(온도, 풍량, 습도 등) 제어 및 조회
Light조명 상태 조회 및 앰비언트 라이트 등 제어
Odometer총 주행 거리, 트립 주행 거리/시간, 주행 거리 단위 조회
Safety차량 경고(Warning) 정보 조회
Seat좌석 위치·각도·기능 제어 및 조회
SideMirror사이드미러 열선 상태 조회/설정
Steeringwheel핸들(스티어링휠) 상태, 열선 조회/제어
Tire타이어 상태 조회
TollETCS(하이패스) 음성 안내 음량 등 조회/설정
TurnSignal방향 지시등 상태 조회
Window창문 제어 및 상태 조회
Wiper와이퍼 제어 및 상태 조회

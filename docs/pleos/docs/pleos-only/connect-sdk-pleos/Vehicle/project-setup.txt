Maven 저장소 등록​
SDK를 내려받을 Maven 저장소를 앱 프로젝트의 settings.gradle에 등록합니다.
Kotlin
Groovy
dependencyResolutionManagement {
...
repositories {
maven {
url = uri("https://nexus-playground.pleos.ai/repository/maven-releases/")
}
...
}
}

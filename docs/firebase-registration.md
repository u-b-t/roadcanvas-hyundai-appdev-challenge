# 완료 그림 Firebase 등록

앱은 익명 인증과 자동 생성한 닉네임을 사용한다. 완료 그림은 기존 Room에 먼저 저장하고, 앱이 실행되는 동안 주기적으로 미등록 기록을 Firebase에 등록한다. 이전에 기기에 저장된 완료 기록도 등록 대상이다. 연결 실패 시 기기 기록은 유지하고 앱이 실행 중이면 재시도한다. 앱이 종료된 동안에는 재시도하지 않으며 다음 실행 때 다시 시도한다.

서버 문서 ID는 해당 기기의 Room 기록 ID다. 같은 익명 사용자와 같은 기록의 재시도는 같은 문서를 사용한다. 경로 청크를 먼저 쓰고 완성 그림 문서를 쓴 다음, 점수가 기존 최고점보다 높을 때만 리더보드 문서를 트랜잭션으로 갱신한다. 중간에 실패해도 다음 시도에서 동일 문서를 다시 사용한다. 동점은 기존 리더보드 기록을 유지한다.

서버 기록을 다른 기기에 내려받거나 기기 기록 삭제를 서버 삭제에 반영하지 않는다. 앱 데이터 삭제나 기기 변경으로 익명 계정을 잃으면 계정 및 기존 기록을 복구할 수 없다. 앱이 보낸 점수와 위치의 진위는 검증하지 않는다. 네트워크 및 실제 차량에서의 장시간 동작은 별도 검증이 필요하다.
